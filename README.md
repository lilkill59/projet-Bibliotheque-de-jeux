# projet-Bibliotheque-de-jeux
projet d'architecture nouvelle génération 

un systeme de gestion du stock de jeux de société pour une bbibliotheque ainsi que les emprunts

gestion du stock : 
ID du jeu | nom du jeu | stock |

gestion des emprunts
ID emprunt | ID emprunteur | ID jeu | date d'emprunt | date de retour max | rendu ? |

règle métier : un emprunt du même jeu par personne, 1 mois d'emprunt max, pas d'emprunt si les stockes sont a 0,
